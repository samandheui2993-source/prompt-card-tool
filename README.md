# 提示词抽卡工具 v26

本地运行的提示词抽卡 / 角色卡工具，零安装、不联网。双击 `提示词工程/抽卡/抽卡.html` 即可使用。

## 目录结构

```
提示词工程/
├─ 首次使用说明.txt          入门说明
├─ 提示词对照.xml            词库总表（约 33.4 万词条）
├─ 提示词总库.xml            含组合库的完整词库
└─ 抽卡/
   ├─ 抽卡.html               网页版主程序
   ├─ 启动网页版.cmd          一键启动网页版
   ├─ 抽卡.cmd                命令行随机抽词
   ├─ 抽卡.ps1                命令行主脚本
   ├─ 按需求.ps1              按需求出词
   ├─ 使用教程.xml            完整使用文档（建议先看）
   ├─ 角色卡.js               28,469 张角色卡（含纯特征版）
   ├─ 抽卡数据.js             词库（含热度）
   ├─ 组合库数据.js           情色组合库 / 血腥组合库
   ├─ 血腥组合库数据.js       血腥组合库
   ├─ 共享常量.js / .json     规则常量（热度档位、特征分组、联动词等）
   ├─ 女性向男同角色.js/.txt  题材角色数据
   └─ 抽卡.html               网页工具
```

## 网页版（推荐）

1. 双击 `提示词工程/抽卡/启动网页版.cmd`，或直接双击 `抽卡/抽卡.html`
2. 「按需求」：输入角色名或一句话需求 → 生成完整提示词（命中角色卡时自动附「角色特征 · 老模型用」+ 纯特征版）
3. 「抽卡」：随机抽词，支持热度档位与热度加权

首次打开需加载本地数据，约 2~3 秒，之后秒开。

## 命令行版

```powershell
# 随机抽词
提示词工程\抽卡\抽卡.cmd

# 按需求出词
powershell -ExecutionPolicy Bypass -File 提示词工程\抽卡\按需求.ps1 "角色名 关键词"

# 常用参数
-MinPosts 1000   # 只抽热度 ≥1000 的词
-WeightPosts     # 按热度加权
-Combos          # 组合库
-Gore            # 血腥组合库
```

完整说明见 `提示词工程/抽卡/使用教程.xml`。

## 说明

- 全部数据在本地文件里，不联网、不上传任何内容。
- 「纯特征版」= 去掉角色名与作品名的外观特征串，用于不认识该角色的模型。
- 角色卡与词库的重建脚本（`_build`）不在本仓库内。
- 剧情与题材属虚构创作素材，使用者需自行遵守所在平台与地区的规则。

## 数据体积

大文件为纯数据（词库、角色卡），单个文件均低于 GitHub 100 MB 上限，因此直接以普通文件入库，未使用 Git LFS。仓库整体约 176 MB，首次克隆会稍慢。
